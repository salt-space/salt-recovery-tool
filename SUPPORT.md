# Support and feedback

Download the application from the
[official releases](https://github.com/salt-space/salt-recovery-tool/releases).
Usage instructions and CLI examples are in [README.md](README.md).

Report reproducible bugs or request features through
[GitHub Issues](https://github.com/salt-space/salt-recovery-tool/issues).
Include the app version, operating system, recovery step and redacted error text.
Never post private keys, seed phrases, Robo Guardian secrets, decrypted shares,
recovered keys, or screenshots showing those values. Public discussion is not a
place to share recovery material.

Wiki, Discussions, Projects and Packages are not feedback channels. External
pull requests do not trigger CI. Maintainers review changes before any trusted
build runs on `main`.
